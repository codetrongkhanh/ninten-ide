# NintenIDE 🚀

**NintenIDE** là một Web IDE chuyên nghiệp mang giao diện chuẩn VS Code, tích hợp trình biên dịch đa ngôn ngữ và hỗ trợ truyền dữ liệu đầu vào (`stdin`) trực tiếp ngay trên trình duyệt web.

## 🌟 Tính năng nổi bật
- **Giao diện chuẩn VS Code**: Dark Theme tối ưu cho lập trình viên, có Sidebar, Tabs quản lý file và Minimap.
- **Đa ngôn ngữ**: Hỗ trợ Python, C, C++, Java, JavaScript, TypeScript, Go, Rust, PHP,...
- **Chạy Code & Nhập Input linh hoạt**: Hỗ trợ truyền nhiều dòng dữ liệu đầu vào (`stdin`) giúp kiểm thử testcase thuật toán dễ dàng.
- **Cấu trúc Modular**: Tách biệt rõ ràng các file `index.html`, `style.css` và `script.js` giúp việc quản lý, tùy biến hoặc đưa lên GitHub trở nên chuyên nghiệp.

## 🛠️ Hướng dẫn sử dụng
1. Tải toàn bộ các file trong kho lưu trữ này về máy.
2. Mở file `index.html` bằng trình duyệt web bất kỳ để trải nghiệm trực tiếp.
3. Hoặc kích hoạt **GitHub Pages** trong phần cài đặt của Repository để xuất bản thành một trang web online hoàn toàn miễn phí!
